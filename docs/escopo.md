# Escopo e etapas

Pata & Afeto é uma landing page acadêmica para tutores e pessoas interessadas em adoção de cães de pequeno porte.

## Estrutura da interface

- Início com carrossel e navegação.
- Catálogo com abas, pesquisa por texto, serviços e perfis ilustrativos de adoção.
- Cartões sobre como funciona a adoção, formulário de contato e rodapé.
- Página de login demonstrativa.

## Etapas

1. Registrar o escopo.
2. Montar a landing page responsiva com HTML semântico, CSS e Bootstrap.
3. Implementar pesquisa, carrossel, formulários, tema e tamanho da fonte.
4. Verificar acessibilidade e documentar evidências.
5. Compor o relatório e publicar pelo GitHub Pages.

A busca deve aceitar palavras com ou sem acento. O carrossel começa parado. Os formulários têm validação local. As preferências persistem entre páginas. Os perfis de adoção são fictícios.
